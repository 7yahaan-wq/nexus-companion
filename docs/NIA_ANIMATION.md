# Nia 动画与素材来源

0.3.0 使用一个透明图集、四组绘制动作、共 16 帧，表达八种语义状态。不是八组独立绘制的动作，也不是 Live2D / Spine。图集文件为 `public/assets/nia/calm.png`，原来的 `public/assets/nia.png` 保留为加载失败时的回退。

## 素材来源

使用内置 `image_gen` 工具，以项目原有 Nia 图片作为身份参考生成。未复制开源项目的角色图片。实际工具输出为 1254 × 1254 RGBA PNG；项目保存原始输出，未重绘或重新编码该文件。

生成文件的本机留存位置：`C:\Users\123\.codex\generated_images\01a0bf31-aae0-7141-8ce0-cbc72b65fcb7\exec-13d3e57c-b99f-4b39-9e96-902e6342363e.png`。此位置仅供本机溯源，运行应用只依赖仓库中的素材。

生成提示的要求摘要（并非逐字请求日志）：

> 以原 Nia 角色为参考，保留银紫短发与呆毛、紫色眼睛、蓝色三角发饰、白色科技外套、黑色内搭、三角项链、盘腿坐姿、笔记本电脑与蓝色小伙伴。生成透明背景、四行四列、16 帧的正方形角色图集，保持比例、留白与风格一致，无文字或网格。第一行：悠闲眨眼；第二行：双手交替敲键盘；第三行：托腮思考、轻微歪头与眨眼；第四行：困倦、闭眼、低头和打哈欠。每帧应有实际的眼睛/手部变化，不用整图位移代替绘制。请求尺寸 2048 × 2048。

生成服务实际返回 1254 × 1254，帧的位置也并非严格等分。额外的独立表情图集生成请求因服务 HTTP 403 未能完成，本次版本不依赖这些未生成素材。

## 动作与状态

| 语义状态  | 动作素材                    | 触发规则                                          |
| --------- | --------------------------- | ------------------------------------------------- |
| idle      | 第 0 行，眨眼               | 默认陪伴                                          |
| working   | 第 1 行，键盘               | 专注中，或两分钟内观测到运行                      |
| thinking  | 第 2 行，思考               | 两分钟内的 STARTING / WAITING                     |
| happy     | 第 0 行，笑脸序列           | 两分钟内完成一个会话                              |
| warning   | 第 2 行，思考并显示提醒标记 | 两分钟内的 WAITING_APPROVAL                       |
| error     | 第 2 行，思考并显示错误标记 | 五分钟内失败的会话                                |
| sleepy    | 第 3 行，困倦               | 本地时间 23:00 至次日 06:00，且没有更高优先级状态 |
| celebrate | 第 0 行，较快的笑脸序列     | 两分钟内完成多个会话                              |

优先级：error → warning → working → thinking → 完成反馈 → sleepy → idle。STARTING / WAITING / WAITING_APPROVAL 是领域预留状态，当前本地 Codex 适配器不保证产生它们；可在设置中预览，不代表支持实时审批。

## 后续修改入口

- `src/domain/avatar.ts`：状态解析、帧序列、每帧停留毫秒数、静态代表帧。
- `src/avatar/niaFrames.ts`：原始图集每帧的偏移和轮廓裁剪。根据透明像素分析得到，每个角色在同一 350 × 350 虚拟画布内显示，脚部基准对齐。CSS 在运行时裁剪邻帧，不修改图片内容。换图集后必须重新标定这些坐标。
- `src/avatar/useSpritePlayback.ts`：逐帧定时器、减少动态效果、页面和 Electron 窗口可见性。卸载、切换动作或暂停时清理定时器。
- `src/avatar/AvatarManager.tsx`：内置图集、自定义资源和 Core 的渲染；自定义资源加载以 ID 配对，避免短暂显示上一个状态的图片。
- `src/avatar/AvatarPreview.tsx`：设置页八状态预览。
- `electron/main.cjs` / `preload.cjs`：窗口隐藏、显示、最小化、恢复的可见性通知，弥补仅使用 `document.hidden` 时部分桌面行为无法暂停的问题。

`avatarMotion` 保存于 `settings/appearance`，缺省视为开启。静态姿态仍随状态切换；该开关不能暂停导入 GIF 文件自身的动画。

验证入口：`tests/avatar.test.cjs` 校验状态时效、夜间边界和素材契约；`tests/nia.cjs` 在真实 Electron 中检查主页保存、八种预览、帧推进、减少动态效果、隐藏/恢复、开关持久化、深浅主题、英文与小窗口。完整验收运行 `npm run verify`。
