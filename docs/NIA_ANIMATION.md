# Nia 动画与素材

当前版本 0.3.3。角色设定图保存在 res/Nia.png，是用户提供的项目参考资源；任何自动清理都不得触碰 res。原始四组 16 姿态图集 public/assets/nia/calm.png 保留作素材历史，新版运行时使用 public/assets/nia/animations 下的八张独立序列帧图。

## 素材制作与播放契约

八种状态各有一张 1448 × 1086 的透明 RGBA PNG，固定四列三行，每格 362 × 362，共 12 张独立绘制的画面。新图基于设定图与旧图集，经内置 imagegen 生成。素材没有复制第三方角色图片。图集中每格大小一致，用户看到的角色、笔记本与蓝色机器人位置保持连续。

运行时每次只显示一格，不再将两张姿态叠加调透明度。帧号、时长、静态代表帧与是否循环由 src/domain/avatar.ts 定义。src/avatar/useSpritePlayback.ts 负责定时、减少动态效果、窗口隐藏暂停；src/avatar/AvatarManager.tsx 裁剪单格显示。空闲、工作、思考、困倦循环；开心、提醒、错误、庆祝播放一次后保持末帧。状态仍由真实专注和本地 Codex 观测决定。

| 状态      | 动作画面       | 自动触发                          |
| --------- | -------------- | --------------------------------- |
| idle      | 呼吸、眨眼     | 白天没有更高优先级状态            |
| working   | 敲键盘         | 专注中，或两分钟内观测到 RUNNING  |
| thinking  | 停顿思考       | 两分钟内观测到 STARTING / WAITING |
| happy     | 小幅开心回应   | 两分钟内一个会话完成              |
| warning   | 抬手提醒       | 两分钟内观测到 WAITING_APPROVAL   |
| error     | 查看失败并平复 | 失败后五分钟                      |
| sleepy    | 困倦、打哈欠   | 23:00–06:00 且没有更高优先级状态  |
| celebrate | 举手庆祝       | 两分钟内多个会话完成              |

失败 → 审批 → 工作/专注 → 等待 → 完成反馈 → 深夜 → 空闲是状态优先级。STARTING、WAITING 和 WAITING_APPROVAL 是领域预留状态；当前本地 Codex 适配器不保证识别。设置页预览对此有明确说明。

静态帧仍随状态变化。系统减少动态效果、关闭角色动画或窗口隐藏时停止播放。自定义 Avatar Pack 格式未改，导入 GIF 自身的动画不受内置开关控制。

## 验证与维护

运行 npm run harness 检查八张图的 RGBA、尺寸、版本与桌面预览；npm run verify 执行完整桌面回归。换图时必须检查 12 格没有完全重复、没有透明度闪烁、边界没有裁掉角色或机器人、首尾衔接自然，并保留 res/Nia.png。项目契约见仓库根目录 AGENTS.md。
