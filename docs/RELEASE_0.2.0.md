# Nexus Companion 0.2.0

- 设置 → 仅保存在本地 → 选择数据保存位置。重启时迁移数据库、资源、备份及日志，并校验数据库。旧目录保留；目标已有同名数据目录时拒绝覆盖。Chromium 缓存与数据路径配置仍放在系统应用目录。
- 欢迎引导可以关闭或按 Esc 跳过。普通弹窗支持关闭按钮、Esc 与点击遮罩。专注页提供返回工作台入口，返回后计时继续。
- 设置增加简体中文 / English。中文默认，导航、首页统计、任务状态、优先级、日历视图等使用中文。英文覆盖主要导航和常用按钮，部分详细帮助文字仍为中文；用户内容及 Codex 输出不翻译。
- Morning 调整为浅色卡片和深色正文，修正状态标签、按钮、弹窗及首页横幅的对比度。增加较小文字字号。
- Codex 连接页说明本地会话读取机制、路径及扫描结果，可选择目录、暂停读取或恢复自动检测。官方登录说明可直接打开；登录仍在官方 Codex 中完成，不收集凭据。
- 学习 Super Productivity 的数据管理与 CodexMonitor 的连接可见性；具体来源见 OPEN_SOURCE_RESEARCH.md。

安装包面向 Windows x64。无代码签名。升级不自动删除原数据；修改数据位置前也可先导出本地备份。

验证：16 项单元测试、11 组桌面验收通过；打包后的程序再次通过完整使用流程和本次可用性验收；便携 EXE 直接启动测试通过。安装器已构建，未替用户执行安装。安装包不包含开发者的会话、凭据或数据库。
