# Nexus Companion 0.3.0

发布日期：2026-09-21。面向 Windows x64。

- 主页增加「记录灵感」，与「添加今日任务」并列。直接打开笔记编辑器，支持标题、Markdown、项目和标签，保存后进入原有笔记列表。
- Nia 增加 16 帧透明角色素材：悠闲眨眼、敲键盘、托腮思考和困倦休息四组动作。八种工作状态通过动作序列、播放节奏、标记和文案反馈；开心/庆祝复用笑脸帧，提醒/错误复用思考帧。
- 设置增加八状态预览和「角色动画」开关。遵循系统减少动态效果设置；窗口隐藏或最小化时暂停动画，恢复后继续。关闭动画后保留状态对应的静态姿态。
- 修正旧失败记录持续占用 Nia 表情的问题：错误反馈保留五分钟，活动观测和完成反馈保留两分钟；专注、深夜和空闲状态按当前情况更新。
- 参考 VS Code Pets 的状态与渲染分离、eSheep 的图集动画组织，未复制第三方代码或角色素材。来源和实际落地见 [开源学习记录](OPEN_SOURCE_RESEARCH.md)。

验证与交付结果见 [验收记录](VERIFICATION.md) 和 [发布状态](PROJECT_STATUS.md)。安装版与便携版均未签名；安装器不会在验收时自动安装到用户系统。

沿用现有本地数据库，不需要手动迁移。旧外观设置缺少动画开关时默认开启，可在设置中关闭。Avatar Pack 格式保持兼容；本次逐帧播放器用于内置 Nia，导入 GIF 的内嵌动画不受角色动画开关控制。
