# Nexus Companion 0.3.1

发布日期：2026-09-21。面向 Windows x64。

- 左侧「笔记」更名为「灵感笔记」，英文为 Ideas & notes，明确与主页记录灵感的关系。
- 主页增加「查看灵感」。在主页或角色菜单中保存灵感后，直接进入灵感笔记列表；取消编辑仍留在原页面。
- 灵感笔记页面说明主页记录的内容保存在这里。原有笔记、搜索和编辑继续使用同一份本地数据，无需迁移。
- 保留左侧「进入专注模式」，移除右侧伙伴栏中重复的专注按钮。

完整 harness 的 16 个阶段通过，包括 20 项单元测试和 12 组桌面验收。新增检查覆盖保存后跳转、取消编辑、查找已保存内容、重启后查找、中英文入口、小窗口布局，以及唯一的侧栏专注入口可以使用。最终发布包结果与校验值见 [发布状态](PROJECT_STATUS.md)。

已有旧版运行时，请先从系统托盘退出旧版，再打开新版。关闭窗口通常只是隐藏到托盘。安装器未签名，验收不会替用户执行安装。
