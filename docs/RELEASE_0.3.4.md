# Nexus Companion 0.3.4（本地待验收）

本版本修复 Nia 序列帧美术中的额外手、手臂错位、人物漂移和相邻格残留。八种状态仍各有 12 张独立画面。

- Nia 改用统一胸像构图，电脑遮住双手、下臂和腿部。银紫短发、蓝紫眼、三角发夹、白色外套、胸前标志和小机器人延续原设定。八组画面分别呈现对应状态。
- 新增可复现的素材标准化脚本，以笔记本蓝色三角为固定锚点，裁掉源图边缘串格并加透明边距。应用加载的是标准化后的四列三行图集。
- 播放器按照实际经过时间确定帧，定时器延迟不会不断拖慢动画。隐藏窗口和减少动态效果设置仍会暂停动画。
- 自动桌面验收新增 8 像素边界透明和笔记本锚点范围检查；项目规范和使用说明已同步。

安装版与便携版均为 Windows x64、未签名。完整桌面回归和 20 项单元测试通过；实际便携版通过隔离环境的启动、桥接、欢迎页与退出检查，打包内容也通过八状态 Nia 界面验收。安装版尚未走安装向导，仍需用户实际安装验收。此版本仅在本机生成，待用户验收通过后再提交或上传 GitHub。res/Nia.png 未修改。
