# Nexus Companion 0.4.0

发布日期：2026-10-08。

这次更新把灵感、任务、时间安排和专注连接起来，并根据真实桌面体验修复容易丢失内容或找不到记录的问题。已整合远端 0.3.11 的 Nia 动画、立绘切换和跨机器开发 harness。

## 日常工作

- 首页首先呈现今日与逾期未完成任务、下一项日程；压缩欢迎区和空 Agent 状态。逾期任务可明确选择移到今天。
- 每日计划选择最多三件重点，填写可用分钟，查看预计负荷、昨日遗留、开工和收工。回顾内容自动保存在本机。
- 项目详情聚合相关任务和灵感，支持继续专注；“下次第一步”自动保存，便于第二天接着工作。

## 灵感与记录

- 新建和编辑笔记自动保存本地草稿，Esc 关闭、切换入口和重启后可恢复；可明确丢弃草稿。
- 保存新灵感后直接选中它，清除旧搜索造成的隐藏；搜索和来源链接可以再次找到它。
- 一键转任务，保留原笔记及项目、标签和正文；重复点击打开已关联任务，不重复生成。
- 全局快速记录提供“灵感 / 任务”切换，记住上次保存类型，展示保存位置，保留 TODO / NOTE 前缀和 Ctrl+Enter。关闭保留草稿。

## 专注与可靠性

- 从任务卡片或项目预选专注任务；离开专注页仍显示计时、暂停和结束操作。
- 完成和提前结束自动计入关联任务的实际用时；暂停时间不计入，不自动把任务标为完成。
- 结束后可选择“完成任务 / 再来一轮 / 休息”。
- 结束记录、累计用时与清理当前计时在一个 SQLite 事务中完成；重试和重启不会重复累计。编辑任务时保留刚新增的专注时间，手动用时修改也有重试去重。

## 操作体验

- 任务表单把描述、标签、关联 Agent 等放到“更多选项”，自动聚焦标题，操作按钮保持可见；未保存修改有关闭保护。
- 新时间块默认从下一个 15 分钟刻度开始；明确选择的日历格子保留原时间。
- Nia 支持收起并记住选择；窄窗口使用独立小栏，不覆盖任务或统计内容。保留 0.3.11 的动画 / 立绘切换、已接受的 idle 播放和其余七种独立 24 帧候选序列；本次没有重新生成或修改角色美术，候选美术仍待用户视觉验收。
- 外观设置前置；时间线显示可读内容；未选择目录的首次引导不再要求填写会被丢弃的项目名称。
- 本地备份增加草稿、每日计划和快速记录偏好，继续排除正在运行的内部计时状态和连接配置。

## 升级说明

已有记录保持兼容，无需手动转换数据库。旧版本已经结束的专注记录不会追溯补算到任务，避免与手填用时重复。新字段由首次使用自动补充；升级前可在设置中导出本地备份。

程序仍保持本地优先、Codex 会话只读观测。没有新增账号、云同步、模型调用或第三方运行依赖。备份包含个人内容；草稿属于可恢复记录，会随本次新版备份导出。

验收结果与安装包校验值见 `VERIFICATION.md`、`PROJECT_STATUS.md`。安装包安装流程未替用户执行。
