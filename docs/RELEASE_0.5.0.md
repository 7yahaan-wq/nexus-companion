# Nexus Companion 0.5.0

日期：2026-10-11。本次增加 Codex 会话 tokens 与 ChatGPT 套餐额度查看功能。

## 查看用量

- Agent 卡片展示会话累计 tokens，详情区分会话累计和最近请求，列出输入、缓存输入、缓存写入、输出、推理输出及总量。缺失值显示 `—`，真实零值显示 `0`；重复快照不累加。
- Agent 页提供独立的账号套餐额度区域，按官方窗口显示观测时剩余比例、重置时间、额外 Credits 及来源。已过重置时间的快照显示待更新，不推算恢复额度。
- 点击“查询当前套餐额度”，通过本机 Codex CLI 查询当前登录的 ChatGPT 账号。详情中的“查询此任务额度”按会话 ID 获取官方估算 Credits 和模型分组。官方没有提供该会话估算时会明确说明。
- 详情中的“刷新当前会话”同时更新本地 tokens 和日志。关闭或切换会话不会接收上一会话迟到的查询结果。

## 数据与能力边界

本地 tokens 是 Codex 最新报告的会话累计计数，不是每轮任务的独立账单。缓存输入和推理输出是细分项，不能重复加到输入/输出中；分叉会话不与来源会话相加。长文件仍采用末尾 2 MB 的有界读取。

套餐额度由账号共享，不能从某个会话的 tokens 精确推算扣减百分点。官方任务 Credits 是估算，不是美元金额，也不换算成套餐百分点。多个额度桶分开展示，历史本地记录不保证来自当前 CLI 账号。

官方查询仅由用户按钮触发，不自动轮询。Nexus 不读取 `auth.json`，不保存密码或令牌，不登录账号、提交提示或控制运行中的会话。查询使用 CLI 自身的账号流程；CLI 可能刷新自己的登录状态。账号查询结果仅保存在界面内存中。旧 CLI、不支持的账号、网络错误或暂无任务估算均有明确的不可用提示。

参考：[官方 App Server 协议](https://learn.chatgpt.com/docs/app-server)、[官方套餐与 Credits 说明](https://learn.chatgpt.com/docs/pricing)。

## 验证与分发

本版已通过 63 项单元测试、22 个完整验证阶段（17 组桌面回归）、40 个应用文件的源码/归档一致性审计，以及八组打包桌面流程和实际便携 EXE 验收。详细结果见 [PROJECT_STATUS.md](PROJECT_STATUS.md)，测试范围见 [VERIFICATION.md](VERIFICATION.md)。测试使用隔离数据库和受控 Codex 记录，官方查询由测试端模拟，不接触个人凭据。

本机另做了只读官方接口探测：当前套餐额度查询成功；最近会话的任务估算暂未提供，已验证对应缺失处理。该探测不是测试夹具，也不会写入仓库中的个人账号信息。

产物为 `dist/NexusCompanion-Setup-0.5.0.exe`、`dist/NexusCompanion-Portable-0.5.0.exe` 与 `dist/SHA256SUMS-0.5.0.txt`。安装包未签名；构建安装器不等于执行过安装向导。Git 源码同步不包含 EXE。

既有工作数据、设置、备份格式和导入头像包继续兼容。Nia 素材和播放器未修改：只有 idle 动画获用户视觉接受，七组非 idle 动画仍为候选。历史版本说明通过 Git 标签保留。

操作说明见 [USER_GUIDE.md](USER_GUIDE.md)，继续开发见 [DEVELOPMENT_HANDOFF.md](DEVELOPMENT_HANDOFF.md)。
