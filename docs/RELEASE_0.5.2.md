# Nexus Companion 0.5.2

日期：2026-10-24。本轮由独立智能体模拟多项目、多任务的日常使用，优先修复筛选下新任务不可见、跨页筛选丢失和拖动排序不可靠的问题。

## 用户可见变化

- 选定项目后，顶部新建任务自动继承该项目；从任务进入来源灵感、日历或其他页面再返回，保留本次会话的关键词、项目和排序。快捷记录显式保存新任务时清除旧筛选，便于找到刚保存的内容。
- 无任务或筛选无结果时说明原因，并提供清除筛选入口。任务卡可直接选择状态，不必拖动或打开编辑窗口；提交中阻止重叠移动，失败保留原界面并显示可重试的错误。
- 手动拖动基于完整目标列排序，隐藏任务保留相对顺序。按日期或优先级显示时，拖动只改变状态，同列拖动不再悄悄修改手动位置，并有明确说明。
- 移动任务、必要位置更新和一条活动记录在同一个 SQLite 事务完成。保留当前数据库中的专注用时和其他字段，拒绝已删除的任务与失效锚点；失败整体回滚，无变化不产生新活动。移动提交后读取失败会明确提示，重试可重新同步列表。

## 验收与兼容

沿用有输入指纹、24 小时有效期和有界执行的 Harness 续跑。当前源码或版本变化会使旧证据失效；只有本轮输入未变化的成功阶段才能复用，不为提高复用数缩小验证范围。固定路径和重现步骤见 [DEVELOPMENT_LOOP.md](DEVELOPMENT_LOOP.md)，当前执行结果与产物哈希见 [PROJECT_STATUS.md](PROJECT_STATUS.md)。

保留现有数据、备份格式、Codex 用量观测和角色包，不新增依赖。Nia 素材与播放器未修改，只有 idle 动画已获用户视觉接受。源码同步不包含 EXE，安装器构建不代表实际安装验收。历史版本说明由 Git 标签保留。
