# Nexus Companion 0.5.3

日期：2026-10-28。独立智能体实际走查后，本轮修复两处日常使用断点。

- 首页“查看日报”等待当前回顾保存后直接打开当日日报。正文、复制及导出包含当天重点任务、可用时间和完整回顾；保存失败保留输入，可从同一入口重试。
- 切换日期隔离读取结果，快速切换不会混入旧日期内容。无计划明确提示；加载或失败时禁用复制导出，提供读取重试。
- 项目详情新增“查看全部任务（数量）”，可访问超出最近五项的历史任务；清除旧关键词，新建继续关联该项目。首页查看全部任务会清除项目筛选，普通侧栏切换仍保留筛选。
- 打包不再提前删除旧可用版本。清理默认预览，完整打包验收通过后才能执行，保留当前版本与一个指定回退版本。

不新增依赖，不迁移用户数据库，不修改 Nia 素材。只有 idle 动画已获视觉接受。沿用有指纹、24 小时有效期及固定边界的 Harness；新路径同时进入源码与打包回归。当前结果、产物哈希及实际清理记录见 [PROJECT_STATUS.md](PROJECT_STATUS.md)，可重复流程见 [DEVELOPMENT_LOOP.md](DEVELOPMENT_LOOP.md)。源码同步不包含 EXE，安装器构建不代表已安装验收。
