# Nexus Companion 0.5.4

2026-11-07。Nia 的这次调整集中在「专心工作」「温柔提醒」和「庆祝完成」。可以在设置的「认识更多面的 Nia」逐个预览这些动作。

专心工作会循环播放，可以观察 Nia 眨眼后回到专注姿势的过程。提醒与庆祝各播放一次，随后停在各自的结束姿势。三种动作都用 Nia 自己的完整源画面重新编排。七组非 idle 动画继续等待用户视觉验收，已验收的 idle 可作为对照。

美术工作流及逐格审查方法见 [Nia 动画与立绘](NIA_ANIMATION.md)。当前版本的桌面验收、可运行包和清理记录见 [项目状态](PROJECT_STATUS.md)。
