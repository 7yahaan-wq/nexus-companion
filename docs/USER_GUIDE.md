# Nexus Companion 0.4.1 使用手册

Nexus Companion 是一款 Windows 本地桌面工作中枢，用于集中管理项目、任务、日程、笔记、专注计时和本机 Codex 会话记录。应用默认只在本机保存数据，不要求 Nexus 账号，也不会自动把你的项目内容上传到云端。

本手册描述 Nexus Companion 0.4.1 的现行功能。此次更新仅清理冗余资料与未使用的衍生素材，保留原有工作流；完整 harness、包审计和打包版验收已通过，实际结果及校验值见 [PROJECT_STATUS.md](PROJECT_STATUS.md)。另一台电脑继续开发见 [START_ON_NEW_PC.md](START_ON_NEW_PC.md)。

## 安装与启动

### 安装版

双击 `NexusCompanion-Setup-0.4.1.exe`，按照安装向导操作。安装向导允许选择程序安装位置。

安装包目前没有商业代码签名证书。Windows 可能显示“未知发布者”或 Microsoft Defender SmartScreen 提示。请确认文件来自你信任的来源，并可使用项目附带的 `SHA256SUMS-0.4.1.txt` 校验文件完整性。

PowerShell 校验示例：

```powershell
Get-FileHash .\NexusCompanion-Setup-0.4.1.exe -Algorithm SHA256
```

将输出与 `dist/SHA256SUMS-0.4.1.txt` 中安装版对应的值比较。

### 便携版

双击 `NexusCompanion-Portable-0.4.1.exe` 即可运行，不需要安装。便携版只是程序免安装，用户数据默认仍保存在 Windows 的 AppData 中。你可以在应用设置里更改数据保存位置。

便携版的 SHA-256 记录在 `dist/SHA256SUMS-0.4.1.txt` 中。

### 系统要求

- Windows 10/11 x64；当前主要在 Windows 11 上验证。
- 建议分辨率不低于 1280 × 720。
- 项目快捷操作需要相应程序已经安装，例如 Git、VS Code、Windows Terminal、Godot 或 Unity。
- 读取 Codex 会话需要本机已有 Codex 会话记录。

## 首次启动

首次启动会显示欢迎引导：

1. 阅读产品说明。
2. 可选择一个已有工作目录。此步骤可以跳过。
3. 已选择目录时，为首个项目填写名称；未选目录时不会展示名称输入，也不会创建项目，可以稍后再添加。
4. 选择 Midnight 深色或 Morning 浅色主题。
5. 选择 Nia 或 Nexus Core 作为工作伙伴。
6. 点击“进入工作台”。

欢迎引导可以通过右上角关闭按钮、按 `Esc` 或点击遮罩区域退出。以后可在“设置”中重新打开欢迎引导。

## 界面结构

应用分为三个主要区域：

- 左侧导航：工作台、Agent 工作台、任务、日程、项目、时间线、灵感笔记和设置。
- 中间内容区：显示当前功能页面。
- 右侧工作伙伴：显示 Nia 状态、提示和常用入口。

窗口顶部会显示当前位置。左侧底部可以进入专注模式，并显示本地数据状态。

右侧伙伴栏可以收起，并记住紧凑显示偏好。窄窗口自动使用独立的小栏，保留内容区空间；角色不再悬浮遮住统计卡或正文。专注运行时，其他页面会显示计时条，方便查看、暂停和结束。

## 工作台

点击首页横幅中的「记录灵感」，填写标题和内容后保存，会进入「灵感笔记」并选中刚保存的内容；旧搜索条件不会将它隐藏。以后点击首页「查看灵感」或左侧「灵感笔记」即可找到记录，并继续编辑、搜索和关联项目。

工作台用于快速查看当天情况：

- 运行中的 AI：最近从本机 Codex 记录观察到的运行状态。
- 今天与逾期任务：今天到期、已经开始、进行中、逾期未完成或选入今日重点的任务。完成和取消的任务不会继续占据这个列表。
- 专注时间：今天已经完成并记录的专注时长。
- 已完成：今天完成的个人任务数量。
- 等待处理：等待中的任务、等待审批或失败的 Agent 记录。
- 下一项日程：优先显示尚未结束的近期日程，并可进入日历安排时间。
- 项目进度：按任务完成数量计算项目进度。

“运行中的 AI”是本地记录的最近观测，不等同于 Codex 实时在线状态。

### 每日计划与回顾

1. 点击“开始今天”或“每日计划与回顾”。
2. 查看昨日遗留，从未完成任务中选最多三件今日重点。
3. 填写今天可专注的分钟数，比较重点任务估时与可用时间。未估时任务会单独提示。
4. 收工时写下今天的收获或下次第一步，点击“收工并保存”。需要继续时可以“重新开工”。

计划与回顾自动保存在本机，并按日期分别记录。开工、选择重点和收工不会更改任务截止日期，也不会自动完成任务；只有明确点击“移到今天”才会把该任务的截止日期改为今天。

## 项目

### 新建项目

1. 打开“项目”。
2. 点击“新建项目”。
3. 输入项目名称。
4. 点击“浏览”选择本机项目目录。
5. 根据需要填写描述、颜色和图标。
6. 保存。

项目目录必须是存在的绝对路径。Nexus 会只读检查目录并识别 Git、Godot 或 Unity 等项目信息。

### 项目快捷操作

项目卡片可能提供以下操作：

- 打开目录。
- 使用 VS Code 打开。
- 在终端中打开。
- 启动检测到的 Godot/Unity 项目。
- 打开项目根目录中的 Markdown、TXT 或 PDF 文档。

如果对应外部程序没有安装，应用会显示错误信息，不会自动安装软件。

### Git 信息

项目详情可显示当前分支、未提交文件和最近提交。Git 检查为只读，不会自动提交、切换分支或修改仓库。

### 继续上次工作

打开项目详情，可以查看关联任务和灵感，继续最近的未完成任务、进入专注，或打开最近灵感。请在创建任务或笔记时选择所属项目，内容才会出现在这里。

“下次第一步”用于留下下次打开项目时的起点，会自动保存；切换页面后仍可恢复，也提供手动保存按钮。它不会创建任务或改写任务状态。

## 任务

### 创建和编辑

1. 打开“任务”。
2. 点击“新建任务”或某列底部的“添加任务”。
3. 填写标题、项目、状态、优先级、截止日期和预计时长；描述、标签、开始日期、实际时长及 Agent 字段在“更多选项”中展开。
4. 点击“保存”。

任务状态包括：

| 状态   | 含义                 |
| ------ | -------------------- |
| 收集箱 | 尚未整理的新事项     |
| 已计划 | 已确定要做           |
| 进行中 | 当前正在处理         |
| 等待中 | 等待他人、条件或资源 |
| 已完成 | 已完成并计入完成统计 |
| 已取消 | 不再继续             |

优先级包括低、中、高和紧急。任务还可以关联项目、Agent 名称和 Agent Task ID。

### 看板操作

- 将任务卡拖到其他列可以更改状态。
- 在同一列拖动可以调整手动顺序。
- 顶部可以按项目过滤、搜索标题/标签，或按截止日期和优先级排序。
- 点击任务标题可以编辑或删除。

### 安排到日程

点击任务卡上的日历图标，或者把任务拖到日历时间格。应用会根据任务信息创建日程草稿，保存后任务与日程会建立关联。从任务按钮打开时，默认选择接下来的 15 分钟刻度，避免默认开始时间已经过去；保存前仍可自行调整日期和时间。

任务卡也提供专注入口。由灵感转换的任务显示“来源灵感”，可直接回到原笔记。

## 日程

### 视图

日程支持月、周、日三种视图。使用左右箭头切换日期范围，点击“今天”回到当前日期。

### 新建日程

1. 点击“新建日程”，或点击/拖入时间格。
2. 填写标题、开始时间和结束时间。
3. 可选择类型、颜色、项目、地点和备注。
4. 根据需要设置每天、每周或每月重复。
5. 保存。

结束时间必须晚于开始时间。跨午夜日程会在两天中分段显示；重叠日程会自动分栏。

### 拖动与调整

- 在周/日视图中拖动日程可以调整开始时间。
- 拖动日程底部可以调整结束时间。
- 编辑、拖动或调整重复日程会修改整个重复系列。0.4.1 尚不支持只修改某一次发生项。

## Agent 工作台与 Codex 连接

### Nexus 如何连接 Codex

Nexus 0.4.1 不会登录你的 OpenAI 账号，也不会连接或控制正在运行的 Codex 进程。它以只读方式扫描本机 Codex 数据目录中的 `sessions` 会话记录，并将可识别的信息展示为 Agent 卡片。

默认目录为：

```text
%USERPROFILE%\.codex
```

如果设置了 `CODEX_HOME`，则使用该目录。

### 连接设置

打开“设置 → Codex 连接”，可以：

- 查看当前读取目录。
- 查看是否发现会话、会话数量和最近扫描时间。
- 点击“重新检测”立即刷新。
- 选择其他 Codex 数据目录；所选目录必须包含 `sessions` 文件夹。
- 暂停读取或重新启用。
- 恢复默认自动检测。
- 打开官方登录说明。

暂停读取不会删除已经写入 Nexus 时间线的历史记录。

### Codex 登录

Codex 登录应在官方 Codex 应用、IDE 扩展或 CLI 中完成。CLI 可以执行：

```powershell
codex login
```

Nexus 不读取 `auth.json`，不保存账号密码或访问令牌。只要本机已有会话记录，本地只读展示不要求在 Nexus 内再次登录。

### Agent 卡片和详情

Agent 页面可以：

- 搜索任务、项目或 Agent 名称。
- 按状态过滤。
- 查看最近公开输出和文件活动。
- 查看工作目录和相关项目。
- 为会话设置显示名称、角色或置顶。
- 打开检测到的项目目录或编辑器。

状态和时长只来自能够明确解析的会话事件。长时间没有新事件的运行记录会显示“状态不可用”。停止、重试、实时审批和发送新提示在 0.4.1 中不受支持。

## 时间线与每日总结

### 时间线

时间线汇总项目、任务、日程、笔记和 Agent 活动。可以按日期、项目、Agent 或任务过滤。

### 每日总结

切换到“每日总结”后，可以生成当天的 Markdown 报告，内容包括：

- 完成的个人任务。
- Agent 完成、失败和等待审批的统计。
- 已记录的专注时间。
- 项目和活动摘要。

报告可以复制到剪贴板或导出为 `.md` 文件。Agent 统计只基于当前可见的本地会话记录，不能当作完整审计报告。

## 灵感笔记

1. 点击左侧“灵感笔记”，或主页的“查看灵感”。
2. 点击“新建笔记”。
3. 输入标题和 Markdown 内容。
4. 可选择关联项目并添加标签。
5. 保存后可以搜索、预览、编辑、删除或转为任务。

笔记支持常见 Markdown 文本格式。为保证安全，笔记不会执行 HTML，也不会加载远程图片。

编辑中的内容自动保存为本地草稿。按 `Esc`、取消或关闭编辑器后，再次打开可以继续；草稿不等同于已正式保存的笔记。“丢弃草稿”会清除对应的未保存修改。保存失败时保留输入，并显示错误信息。

在笔记正文上方点击“转为任务”，会将标题、正文、项目和标签带入关联任务，原笔记保留。重复点击会打开已有的关联任务，避免重复创建。

## 专注模式

1. 点击左侧“进入专注模式”，或使用任务卡、首页任务和项目详情中的专注入口。右侧伙伴栏不再重复显示相同的常驻入口。
2. 选择 25 分钟、50 分钟，或输入 1–480 分钟的自定义时长。
3. 可关联一个未完成任务，也可以选择自由专注。
4. 点击“开始专注”。

进行中可以暂停、继续或“结束并记录”。点击“返回工作台”或按 `Esc` 只会离开专注页面，计时会在后台继续，其他页面仍显示计时条。计时到期会正常完成；需要提前结束时点击“结束并记录”。

专注状态由主进程保存；关闭窗口或应用异常重启后，会根据保存的截止时间恢复。正常计时结束时可发送 Windows 通知。

已完成和提前结束的专注都会把实际用时累计到关联任务，并保留原先手填的实际时长。重复保存同一专注不会重复加时；未关联任务的自由专注只记录自身时长。旧版本已经结束的专注不会追溯回填。

结束后的提示允许你选择完成任务、继续专注或休息。完成一轮专注本身不会自动把任务改为已完成。

## Nia 工作伙伴

右侧工作伙伴会根据当前情况显示空闲、工作、思考、完成、警告、错误、深夜或庆祝状态。点击角色图像可打开快捷菜单，进入任务、Agent、笔记、专注或工作台。

在设置中可以选择：

- Nia：已接受的悠闲动画完全保留。其他七种状态使用各自 24 张完整候选画面，分别表达专注、思考、开心、提醒、担忧、困倦和庆祝；只有悠闲已获用户视觉接受，其余仍待接受。图集加载解码后逐格播放，不叠图、不局部变形、不补帧。右上角可切换「动画／立绘」，选择重启后保留。
- Nexus Core：简洁图形角色。
- 自定义 Avatar Pack：导入本地角色资源包。

「认识更多面的 Nia」可以逐一预览八种状态；选择状态后，角色下方会说明它在什么工作情况下自动出现。启动、等待和审批状态的识别取决于本地 Codex 记录，并不保证实时可用。「角色动画」可关闭内置动画并保留对应姿态，重启后仍记住设置。系统开启减少动态效果，或窗口隐藏/最小化时，也会暂停动画；导入 GIF 自身的动画不受此开关控制。旧失败记录超过五分钟不再持续占用表情。

Avatar Pack 的格式和制作方法见 [Avatar Pack 文档](AVATAR_PACK.md)。

悠闲、工作、思考和困倦会循环播放；开心、提醒、担忧和庆祝反应播放一次后停留。静态模式使用八张状态立绘，仍按工作状态切换。测试通过或源码上传只说明对应工程检查，不代表新角色画面已经通过用户视觉验收。

## 搜索与快速记录

### 全局搜索

在窗口内按 `Ctrl + K`，或点击左侧“快速搜索”。可以搜索项目、任务、日程、笔记和 Agent，也可以运行创建任务、创建笔记、打开设置等命令。

使用上下方向键选择结果，按 `Enter` 打开，按 `Esc` 关闭。

### 快速记录

按 `Ctrl + Shift + Space` 打开快速记录：

```text
TODO 完成登录页设计
NOTE 今天的用户反馈要点
```

- 以 `TODO` 开头会创建任务。
- 以 `NOTE` 开头会创建笔记。
- 没有前缀时，按窗口中选中的“灵感 / 任务”类型保存；首次默认灵感，之后记住上次成功保存的类型。
- 窗口会显示当前保存位置。前缀优先于类型选择，适合习惯键盘输入的用户。
- 关闭会保留草稿，下次可继续。正式保存笔记后会打开并选中该笔记。

全局快捷键可能被其他程序或另一个 Nexus 实例占用。此时设置页会显示提示；在 Nexus 窗口内仍可使用快捷键，也可以从托盘菜单进入快速记录。

## 外观、语言与通知

### 语言

在“设置 → 语言与地区”选择简体中文或 English。主要导航和常用操作会立即切换。项目名称、笔记、任务内容和 Codex 原始输出保持原文。0.4.1 的部分详细帮助文字仍为中文。

### 主题和背景

外观设置包括：

- Midnight 深色主题。
- Morning 浅色主题。
- 强调色。
- 柔和渐变、纯色或本地图片背景。
- 背景模糊、亮度、可见度和面板不透明度。

导入的背景图片会复制到 Nexus 数据目录；移动或删除原图不会影响已经导入的背景。

### 通知

可以分别开关 Agent 完成、Agent 失败、等待审批、日程提醒和专注结束通知。“发送测试通知”可检查 Windows 通知服务是否可用。

即使应用报告通知可用，Windows 勿扰模式或系统通知设置仍可能阻止弹窗。

## 数据位置

### 默认位置

默认数据目录为：

```text
%APPDATA%\Nexus Companion
```

主要内容：

| 内容                         | 文件或目录     |
| ---------------------------- | -------------- |
| 项目、任务、日程、笔记和设置 | `nexus.sqlite` |
| 导入的背景和 Avatar 图片     | `assets\`      |
| 应用日志                     | `logs\app.log` |
| 恢复前自动快照               | `backups\`     |

### 更改保存位置

1. 打开“设置 → 仅保存在本地”。
2. 点击“选择数据保存位置”。
3. 选择一个父文件夹。
4. 确认界面显示的新目标路径。
5. 点击“重启并迁移数据”。

应用会在所选文件夹中创建 `NexusCompanion-Data`，复制数据库、资源、备份和日志，然后执行 SQLite 完整性检查。迁移成功后使用新目录，旧目录会保留，便于手动确认和回退。

目标位置如果已经存在同名 `NexusCompanion-Data`，应用会拒绝覆盖。不能选择当前数据目录内部的位置。迁移前可以点击“取消迁移”。

路径选择配置和 Chromium 缓存仍保存在系统 AppData。使用移动磁盘时，请确保启动 Nexus 前磁盘已经连接；不要在 Nexus 运行时使用同步工具实时同步数据库目录。

## 备份与恢复

### 导出备份

1. 打开“设置 → 数据安全”。
2. 点击导出备份。
3. 选择文件保存位置。
4. 应用生成 `.nexus` 备份文件。

备份包含可恢复的工作数据、允许导出的设置和已引用的本地图片，并带有 SHA-256 完整性校验。0.4.1 还包含每日计划与回顾、笔记/快速记录草稿和记录类型偏好；不包含 Codex 登录凭据、运行中的专注计时或连接目录配置。备份可能包含个人任务、笔记、未正式保存的草稿和项目路径，请像私人文档一样保管。

### 恢复备份

1. 点击选择/导入备份。
2. 查看创建时间、记录数和校验值预览。
3. 确认恢复。

恢复前，应用会在当前数据目录的 `backups` 文件夹生成自动快照。恢复以事务方式合并记录；不会清空与备份无关的现有记录。

### 数据完整性检查

数据安全区域可以运行 SQLite `quick_check`。显示 `ok` 表示数据库结构检查通过。如果检查失败，应先退出应用并保留整个数据目录副本，再处理问题。

## 托盘和退出

点击窗口右上角关闭按钮通常只会隐藏窗口，Nexus 继续在系统托盘运行。专注计时、Codex 扫描和日程提醒也会继续。

托盘菜单包含：打开 Nexus、打开 Agent 工作台、快速记录、开始专注和 Exit（完全退出）。

在复制数据库、移动数据目录或卸载前，请从托盘选择 Exit 完全退出。

## 升级与卸载

### 升级

安装新版前建议导出一次 `.nexus` 备份。退出托盘中的旧版本后运行新版安装程序。0.4.1 不会主动删除现有数据。

安装版和便携版如果使用同一 Windows 用户，默认会访问同一个 AppData 数据目录。不要同时运行多个版本，否则全局快捷键可能冲突，并可能同时访问数据文件。

### 卸载

卸载程序只负责移除应用程序。需要保留工作数据时，不要删除 `%APPDATA%\Nexus Companion` 或自选的 `NexusCompanion-Data`。

如果确定不再需要任何数据，请先确认备份，再手动处理数据目录。应用不会自动上传或代为保存这些数据。

## 故障排查

### Windows 阻止安装或提示未知发布者

0.4.1 没有代码签名证书。先核对来源和 SHA-256；确认无误后，再使用 Windows 提供的继续运行入口。不要跳过来自不明来源文件的警告。

### 打开窗口后像是退出了

关闭按钮会把应用隐藏到托盘。检查任务栏右侧托盘区域，双击 Nexus 图标或选择“Open Nexus”。

### 弹窗无法关闭

0.4.1 支持右上角关闭按钮、`Esc` 和点击遮罩关闭。笔记和快速记录会先保存草稿；普通实体表单在存在未保存修改时会提示是否放弃。保存操作进行中可能短暂禁用关闭，以防重复提交或中断写入。如果出现持续错误，请先记录错误提示，在设置中查看日志。

### 全局快速记录快捷键无效

- 确认没有运行两个 Nexus 实例或旧版便携程序。
- 检查是否有其他软件占用了 `Ctrl + Shift + Space`。
- 在 Nexus 窗口内尝试相同快捷键。
- 使用托盘菜单的 Quick Capture。

### 看不到 Codex 会话

1. 确认已在官方 Codex 中实际开始过任务。
2. 打开“设置 → Codex 连接”，查看当前路径。
3. 点击“重新检测”。
4. 如果使用自定义 `CODEX_HOME`，选择包含 `sessions` 的目录。
5. 确认没有点击“暂停读取”。

Nexus 不会通过账号登录从云端下载会话。CLI 会话只有写入本地记录后才能显示。

### Agent 状态不准确或显示不可用

本地 JSONL 不是其他 Codex 进程的实时接口。记录超过两分钟没有新事件时，Nexus 不会继续猜测“运行中”，而会显示状态不可用。这是数据来源的能力边界。

### Morning 模式仍看不清

先把背景类型切换为柔和渐变或纯色，并提高面板不透明度。使用本地图片时可降低背景可见度、调整背景亮度。若问题持续，可截图并附上 Windows 缩放比例、分辨率和设置参数进行反馈。

### 数据迁移失败

- 确认目标磁盘可写且空间充足。
- 确认目标中没有已有的 `NexusCompanion-Data`。
- 不要选择当前数据目录或其子目录。
- 原数据目录会保留；查看 `logs\app.log` 获取错误原因。
- 解决问题后重新选择位置，或取消待迁移状态继续使用原目录。

### 日程或通知没有弹出提醒

- 确认 Nexus 仍在托盘运行。
- 检查设置中的通知分类开关。
- 检查 Windows 通知和勿扰设置。
- 使用“发送测试通知”验证系统接口。

### 在哪里查看日志

打开“设置 → 仅保存在本地”，点击“打开日志目录”。主要日志文件为 `logs\app.log`。

日志可能包含本机路径和错误上下文。提交问题前请先检查并删除不希望分享的信息。

## 隐私和能力边界

- 工作数据默认只保存在本机。
- Nexus 0.4.1 没有自有账号、云同步或遥测系统。
- 不读取 Codex 登录凭据，不发送提示，不启动或停止 Agent，不消耗模型额度。
- 点击仓库链接或官方说明会在系统浏览器中打开外部网站。
- 导出的备份、日志和截图可能包含个人内容或本机路径，分享前应自行检查。
- 安装包未签名；请通过可信渠道分发并附带 SHA-256 校验文件。
